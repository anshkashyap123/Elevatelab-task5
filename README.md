# Task 5 - Wireshark Network Traffic Analysis

## 🎯 Objective
Capture live network packets and identify basic protocols and traffic types using Wireshark.

## 🧰 Tools Used
- Wireshark

## 📝 Steps Followed
1. Installed and opened Wireshark.
2. Captured live traffic on active network interface.
3. Browsed websites and pinged servers to generate traffic.
4. Stopped capture after 2 minutes.
5. Applied filters to identify protocols.

## 🔍 Protocols Identified
| Protocol | Description |
|----------|-------------|
| HTTP     | Web traffic protocol |
| DNS      | Domain name resolution |
| TCP      | Reliable transmission control protocol |
